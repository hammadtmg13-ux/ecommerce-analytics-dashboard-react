# E-Commerce Analytics Dashboard

An e-commerce analytics dashboard built with React 18, with components and hooks, instead of plain HTML.

## Features

- KPI cards for Total Revenue $124,500, Total Orders 3,420 and Conversion Rate 4.2%, with mini bar charts
- Revenue Overview chart with Weekly, Monthly and Yearly tabs and hover tooltips
- Traffic Sources donut chart
- Top Selling Products bars, with Tech Accessories on top
- Customer Satisfaction gauge at 4.8, with star rating breakdown
- Recent Orders list with live search filter
- React code panel showing the App.jsx component structure

## Tech Stack

- React 18
- JavaScript (JSX)
- CSS
- SVG charts

## Run it

Open `index.html` in a browser. No build step is needed, React is vendored into the page.
